## 발견한 문제
- [필수] 지금 어느 메뉴에 있는지 화면에서 구분되지 않음
  - 판단: 글 목록/글 보기에서 "글 목록", 글쓰기에서 "글쓰기"가 표시되어야 하는데 두 버튼이 항상 같은 모양임.
  - 근거: 1280px와 375px 모두에서 확인했습니다. 마우스를 메뉴 밖으로 치우면(제목 위로 이동) 두 버튼이 똑같이 보임. 마우스를 올렸을 때만 잠깐 진해짐(마우스 올림 효과일 뿐 현재 위치 표시가 아님). 글 보기와 글쓰기 화면 모두 해당.
  - 재현 방법: 1. 페이지를 연다. 2. "글쓰기"를 누른다. 3. 마우스를 제목 쪽으로 옮긴다. 4. 두 메뉴 버튼이 같은 색, 같은 테두리인지 본다.
  - 기대한 결과: 현재 메뉴가 굵게, 밑줄, 색 등으로 구분됨.
  - 실제 결과: 구분 없음. 스크린리더용 "현재 위치" 표시도 접근성 트리에서 보이지 않음.
  - 확신도: 높음

- [권장] 넓은 화면의 글 화면에도 "목록으로" 버튼이 보임
  - 판단: 목록이 이미 왼쪽에 보이는데 "목록으로" 버튼이 같이 보임. 기준은 휴대폰에서 쓰는 버튼으로 적혀 있음.
  - 근거: 1280px에서 글을 열었을 때 확인.
  - 기대한 결과: 넓은 화면에서는 안 보임(또는 의도된 것인지 확인 필요).
  - 실제 결과: 항상 보임.
  - 확신도: 중간
  - 사람이 결정할 것: 의도된 것인지.

- [권장] 글쓰기 중 글 제목을 누르거나 메뉴를 옮기면 입력 내용이 말없이 사라짐
  - 판단: 화면에 "화면을 벗어나면 사라집니다" 안내는 있음. 하지만 긴 글을 쓰던 꼼꼼한 사용자가 실수로 누르면 확인 없이 날아감.
  - 근거: 제목/본문을 입력하고 "글 목록"을 누른 뒤 다시 글쓰기에 들어가면 빈 칸으로 돌아옴. 안내문이 입력칸 위에 있음.
  - 기대한 결과: 현재 단계에서는 안내로 충분할 수도 있음.
  - 실제 결과: 확인 없이 삭제됨.
  - 확신도: 높음(동작은 확실). 개선 필요 여부는 제품 판단.
  - 사람이 결정할 것: 이탈 확인을 넣을지.

- [참고] 새로고침하거나 뒤로가기를 누르면 처음 화면으로 돌아가고 주소도 안 바뀜

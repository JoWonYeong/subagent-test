# 기능별 기록

`/feature` 커맨드를 실행하면 기능마다 폴더가 생기고 아래 파일이 쌓인다.

| 파일 | 작성자 | 내용 |
|---|---|---|
| request.md | 메인 | 요청 원문 |
| log.md | 메인 | 단계별 진행 기록 |
| plan.md | planner → 메인 | 최종 기획안, 승인 요청, 결정 사항 |
| plan-v1.md | planner | UX 반영 전 기획안 |
| ux-review-1.md | ux-designer | 1라운드 전체 검토 |
| ux-review-2.md | ux-designer | 2라운드 필수 항목 확인 |
| implementation.md | 메인 | 변경 내역, 임의 판단, 불확실한 부분 |
| review.md | code-reviewer | 코드 리뷰 |
| qa.md | qa-customer | QA 결과 |
| ux-review-final.md | ux-designer | 구현된 화면 검토 |
| report.md | 메인 | 최종 보고 |

# UX 기준 (ux-designer가 읽음)

## 화면 상태
- 모든 데이터 영역은 로딩, 빈 상태, 에러, 정상 상태를 가진다.
- 빈 상태에는 다음에 할 행동을 안내한다 (예: "첫 할 일을 추가해보세요").
- 에러는 무엇이 잘못됐는지와 어떻게 해결하는지를 함께 보여주고, 재시도 수단을 둔다.

## 피드백
- 사용자의 행동에는 0.1초 안에 눈에 보이는 반응이 있어야 한다.
- 되돌릴 수 없는 행동(삭제 등)은 확인을 받거나 되돌리기를 제공한다.

## 접근성
- 모든 기능은 키보드만으로 사용할 수 있어야 한다.
- 버튼과 입력에는 보이는 라벨 또는 aria-label이 있어야 한다.
- 포커스 위치가 항상 보여야 한다.
- 색만으로 정보를 전달하지 않는다.

## 반응형
- 기준 폭: 모바일 375px, 데스크톱 1280px
- 터치 영역은 최소 44px

## 문구
- 사용자의 말로 쓴다. 개발 용어를 쓰지 않는다.
- 버튼은 동사로 쓴다 (예: "저장", "추가").
